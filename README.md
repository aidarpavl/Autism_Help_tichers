# Qadam

Платформа на Streamlit для обучения и сопровождения детей с аутизмом: кабинет учителя и кабинет ребёнка в одном приложении.

## Что объединено

| Источник | Функции в Qadam |
|---|---|
| ABA Cards | Свои карточки и уроки, учёт проб сразу нескольких учеников, критерий освоения, графики |
| «Аутизм: Общение», PECS | Коммуникатор: галерея карточек, полоса предложения, озвучка, журнал фраз |
| CanPlan | Пошаговые задания с фото, текстом и аудио, запросы помощи, журнал выполнения |
| Autism Tracker Pro | Дневник «до — поведение — после», настроение, триггеры, отчёты |
| Cuedin | Адаптивный темп: число вариантов, подсказка и длина занятия зависят от самостоятельных ответов |

Дополнительно: регистрация учителей и учеников (по коду учителя), профиль и смена пароля, загрузка КТП (xlsx, csv, docx, pdf, txt), поурочные планы по темам и целям, автоматические карточки, отчёты по каждому ребёнку, экспорт в Word.

## ИИ-отчёт

1. Система считает показатели за период и находит проблемы по правилам.
2. Для каждой проблемы ИИ сам пишет отдельный промт. Учитель видит его, может изменить и выполнить заново.
3. Каждый промт выполняется, ответы собираются в отчёт.

Без ключа ИИ всё работает на встроенных методических шаблонах. В ИИ уходят только обезличенные данные и только при отметке о согласии родителей. Имя заменяется псевдонимом, контакты и дата рождения не передаются.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Публикация на Streamlit Community Cloud

1. Загрузите этот код в репозиторий GitHub.
2. На share.streamlit.io создайте приложение, главный файл `app.py`.
3. В Settings → Secrets вставьте настройки по образцу `.streamlit/secrets.toml.example`.

## Где хранятся данные

На Streamlit Cloud локальные файлы пропадают при перезапуске. Поэтому база копируется в **отдельный приватный** репозиторий GitHub и восстанавливается оттуда при старте.

1. Создайте пустой приватный репозиторий, например `qadam-data`, с файлом README.
2. Создайте fine-grained токен только для него с правом Contents: Read and write.
3. Укажите `GITHUB_BACKUP_REPO` и `GITHUB_BACKUP_TOKEN` в Secrets.

Копия создаётся примерно через 30 секунд после изменений. В публичный репозиторий приложение писать откажется. Перед работой с реальными детьми получите согласие родителей и проверьте требования законодательства о персональных данных.
